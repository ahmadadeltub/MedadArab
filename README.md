# مداد الذكي - منصة تحسين الخط العربي بالذكاء الاصطناعي

منصة متطورة تساعد الطلاب على تحسين مهاراتهم في الخط العربي باستخدام تقنيات الذكاء الاصطناعي والتحليل الفوري.

## المميزات
- تحليل فوري للميل، السُمك، وثبات خط الأساس.
- لوحة تدريب تفاعلية تدعم حساسية الضغط.
- اقتراحات ذكية مخصصة لكل طالب.
- تصميم عصري وفاخر يدعم اللغة العربية بشكل كامل.

## التشغيل المحلي
1. تأكد من تثبيت Python 3.
2. ثبت المكتبات اللازمة:
   ```bash
   pip install -r requirements.txt
   ```
3. شغل التطبيق:
   ```bash
   python app.py
   ```

## النشر والاستخدام (Deployment)
لجعل الموقع متاحاً لجميع الطلاب في أي مكان، يمكنك استضافة المشروع بسهولة:

### 1. عبر Vercel (مستحسن)
المشروع جاهز للنشر على Vercel بضغطة واحدة:
- اربط حساب GitHub الخاص بك بموقع [Vercel](https://vercel.com).
- اختر المستودع (MedadArab).
- اضغط **Deploy**. سيتعرف Vercel تلقائياً على إعدادات Flask.

### 2. عبر Render
- أنشئ حساباً على [Render](https://render.com).
- اختر **New Web Service**.
- اربط المستودع من GitHub.
- الإعدادات:
  - **Runtime**: `Python`
  - **Build Command**: `pip install -r requirements.txt`
  - **Start Command**: `gunicorn app:app`
